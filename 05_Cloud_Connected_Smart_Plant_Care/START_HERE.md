# Start here

## To run it on your laptop

1. Install Python 3.12 or newer.
2. Extract the complete ZIP.
3. Run Start-Windows.ps1, or follow the README commands.
4. Open http://127.0.0.1:8000.
5. Click **Try interactive demo**. The sensors run automatically.

No physical hardware or pre-issued password is needed. To keep your garden, create an account and save the recovery code shown once.

## To let other people use it

Open **docs/DEPLOYMENT.md**. It explains the chosen beginner setup: Render for the app and Supabase for the persistent database. Your hosting accounts are required to publish the live link. A ZIP on GitHub alone does not run a website.

Use the GitHub ZIP to upload clean source. It has no passwords, local database or installed dependency folders. The complete ZIP also contains the compiled dashboard. Both need initial Python dependency installation for local use.

The report is reports/PROJECT_REPORT.md. The ready-to-edit LinkedIn material is docs/LINKEDIN_POST.md. Screenshots and a cover image are in screenshots/.
